# 11 — Стратегия тестирования

Связано: [10-roadmap-and-plan.md](10-roadmap-and-plan.md) (критерии приёмки фаз), все доки компонентов.
Принцип: писать тесты **вперёд** (навык `superpowers:test-driven-development`) и проверять заявления
фактами (навык `superpowers:verification-before-completion`).

## 1. Уровни тестирования

| Уровень | Где | Чем |
|---|---|---|
| Unit | Rust-крейты, Swift-модули | `cargo test`; XCTest |
| Integration | ядро ↔ мок-iPhone по loopback | Rust-тесты с `tools/mock-iphone` |
| Эмуляция канала | транспорт/адаптация | throttling/задержка/потери на loopback |
| Платформенные/ручные | виртуальная камера, реальный iPhone | чек-листы (ниже) |
| Производительность/soak | конвейер | длительные прогоны, метрики |
| Перцептивные | visually-lossless | сравнение глазом/метрики |

## 2. Unit (ключевые точки)

- **`ccp-protocol`:** round-trip control JSON (все типы из [03](03-protocol.md) §6); кодек/декодек
  бинарного media-заголовка (28 байт, поля, LE), граничные значения; неизвестные поля игнорируются.
- **`adaptive`:** `select_mode` на табличных входах (G × caps × транспорт × ограничения) → ожидаемый
  режим (см. [06](06-adaptive-engine-and-speedtest.md) §4); автомат адаптации (последовательности
  сигналов → step_up/step_down с гистерезисом/cooldown).
- **`mediapipeline`:** нормализация форматов в NV12; политика drop-oldest при переполнении; тайминг.
- **`session`:** переходы state machine; маршрутизация команд; обработка дублей/таймаутов.
- **iOS:** упаковка media-заголовка == формат [03](03-protocol.md); `Codable` round-trip; автомат
  `SessionController`.

## 3. Integration (мок-iPhone)

`tools/mock-iphone` (Rust) реализует клиентскую сторону CCP: handshake, телеметрия, генерация media
(raw и «закодированных» синтетических кадров), отклик на `SET_CAMERA/SET_MODE/SPEEDTEST_START`.
Позволяет тестировать **весь путь ядра** без телефона:

- handshake/auth (успех и отказы: неверный токен, несовместимая версия);
- обмен `CAMERA_LIST`/`SET_CAMERA`;
- видео-путь до `FrameSink`-мока (счётчик кадров, проверка формата/тайминга);
- тест скорости (ramp) → корректный `recommendedMode`;
- разрыв/переподключение.

## 4. Эмуляция канала

Обёртка транспорта, вносящая управляемые задержку/джиттер/потери/ограничение полосы. Проверяем:
- деградацию **без обрывов** при сужении полосы (NFR-4);
- отсутствие роста задержки (drop-oldest работает) (NFR-2);
- корректные шаги адаптации и восстановление при улучшении канала.

## 5. CI-гейты

- Rust: `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test` (все крейты).
- UI: `eslint`, `prettier --check`, `tsc --noEmit`, сборка.
- macOS-раннер: сборка iOS-скелета и macos-extension (где возможно без устройства).
- PR не мёржится с красным CI.

## 6. Ручные чек-листы

### 6.1. macOS v1 (Definition of Done — [01](01-vision-and-requirements.md) §7)

- [ ] Установка ПК + iOS, привязка по QR < 60 c (DoD-1).
- [ ] «ClearCam» виден и работает в Zoom, Google Meet (браузер), OBS, QuickTime (DoD-2).
- [ ] Переключение каждого объектива (front/wide/ultra/tele) с ПК отражается < 1 c (DoD-3).
- [ ] Заряд телефона и метрики обновляются ≥1 Гц (DoD-4).
- [ ] Тест скорости → рекомендованный режим; задержка соответствует NFR-1 (DoD-5).
- [ ] USB (iPhone 15 Pro+): истинно несжатый 1080p60; Wi-Fi: авто visually-lossless 1080p (DoD-6).
- [ ] Просадка/восстановление Wi-Fi без обрыва (DoD-7).
- [ ] Все авто-тесты зелёные (DoD-8).
- [ ] Разрыв связи → «Нет сигнала», камера не пропадает; авто-переподключение.
- [ ] Перегрев/низкий заряд → предупреждение/адаптация.

### 6.2. Матрица устройств/каналов

Каждый объектив × {Wi-Fi, USB} × {RAW, Lossy, Авто}; iPhone с USB-C USB3 и без (USB2/Lightning).

## 7. Перцептивная проверка visually-lossless

- Сравнить кадры encoded-режима с raw-эталоном на типовом контенте (лицо/движение/детализация/текст).
- Метрики как ориентир (PSNR/SSIM/VMAF), решающий критерий — отсутствие видимых артефактов.
- Откалибровать таблицу `hevc_target` ([06](06-adaptive-engine-and-speedtest.md) §2.2) по результатам.

## 8. Производительность и soak

- Длительные прогоны (часы) на целевом режиме: нет утечек, нет роста задержки/памяти, стабильный fps.
- Замер CPU/GPU/энергии на ПК и нагрева/разряда на iPhone.
- Метрика glass-to-glass (через синхронизацию часов, [03](03-protocol.md) §8) в пределах NFR-1.
