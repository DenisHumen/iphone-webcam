# 13 — Глоссарий

- **CCP (ClearCam Protocol)** — прикладной протокол между iPhone и десктопом. См. [03](03-protocol.md).
- **Control plane / Media plane** — два логических потока: управление (JSON) и видео (бинарь). Идут по
  двум TCP-соединениям.
- **Source (источник)** — абстракция активного источника видео (в v1 — один iPhone). Задел под несколько
  телефонов. См. [02](02-architecture.md) §5.
- **RAW (истинно несжатое)** — передача необработанных пикселей без сжатия. Здесь — **NV12 (YUV 4:2:0)**.
- **Visually-lossless (визуально без потерь)** — лёгкое сжатие (HEVC/H.264 на высоком битрейте),
  неотличимое глазом на типовом контенте.
- **YUV 4:2:0 / NV12** — формат пикселей: яркость (Y) в полном разрешении + цветность (CbCr) в
  пониженном; 12 бит/пиксель. **NV12** — biplanar-раскладка (плоскость Y + чередующаяся CbCr). Нативен
  для камеры iPhone и удобен стокам камер.
- **Full range / Video range** — диапазон значений Y/CbCr (0–255 vs 16–235). Флаг в media-заголовке.
- **AU (access unit)** — один закодированный кадр. Состоит из **NAL units**.
- **NAL unit** — единица закодированного потока H.264/HEVC. Передаётся length-prefixed.
- **VPS/SPS/PPS** — наборы параметров кодека, нужные декодеру для инициализации; шлются в `config`-кадре
  и перед keyframe.
- **Keyframe (I-frame)** — самодостаточный кадр, с которого можно начать декодирование.
- **VideoToolbox** — аппаратный кодек/декодек Apple (iOS/macOS).
- **AVFoundation** — фреймворк захвата медиа Apple (камера, форматы).
- **CMIO / Camera Extension (CMIOExtension)** — Core Media I/O; современный способ создать системную
  виртуальную камеру на macOS (System Extension). См. [09](09-tech-stack.md).
- **System Extension** — изолированный системный компонент macOS (нужны подпись/одобрение).
- **MFCreateVirtualCamera** — API Media Foundation (Windows 11) для системной виртуальной камеры.
- **v4l2loopback** — модуль ядра Linux, создающий виртуальное устройство `/dev/videoN`.
- **usbmuxd** — демон (libimobiledevice), мультиплексирующий TCP-подобные соединения по USB к iOS-
  устройствам. Делает USB «обычным сокетом» для приложения.
- **mDNS / Bonjour** — обнаружение сервисов в локальной сети (тип `_clearcam._tcp`).
- **Goodput** — фактическая полезная пропускная способность (а не пиковая скорость линка).
- **RTT** — round-trip time, время туда-обратно (через PING/PONG).
- **Jitter (джиттер)** — вариативность задержки/межкадровых интервалов.
- **Glass-to-glass latency** — задержка «от стекла камеры до стекла экрана», полная сквозная.
- **Headroom (запас)** — доля измеренного goodput, которую закладываем под пики (по умолчанию 0.70).
- **Drop-oldest** — политика: при переполнении буфера выбрасываем самый старый кадр (бережём задержку).
- **Hysteresis / cooldown** — приёмы против «дёрганья» при адаптации (вверх — медленнее/реже, чем вниз).
- **Tauri** — фреймворк десктоп-приложений: Rust-бэкенд + системный WebView (фронтенд на вебе).
- **FrameSink** — трейт потребителя кадров на десктопе (виртуальная камера, превью, запись).
- **Transport adapter** — слой, выдающий ядру `(ControlStream, MediaStream, PeerInfo)` независимо от
  Wi-Fi/USB.
