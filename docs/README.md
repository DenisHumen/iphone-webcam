следующий участник — человек или ИИ-агент — мог продолжить работу без потери контекста и без
необходимости перепринимать уже принятые решения.

**Язык:** проза — русская; все технические термины, идентификаторы, имена полей протокола,
команды, пути и код — английские (для точности и совместимости с кодом).

## Снимок проекта (TL;DR)

- **Что:** iPhone → (Wi-Fi/USB) → десктоп → системная виртуальная камера. Несжатое/почти несжатое видео.
- **Назначение:** виртуальная камера **и** просмотр/управление на десктопе.
- **Качество:** гибрид — истинный raw, когда сеть тянет, иначе «визуально без потерь». Решает тест скорости.
- **Камеры:** объективы одного iPhone сейчас; абстракция `Source` под несколько телефонов в будущем.
- **Транспорт:** Wi-Fi + USB под единым протоколом; кабель приоритетнее.
- **Звук:** в v1 нет; протокол заранее допускает добавление аудио-дорожки.
- **Платформы:** macOS (первой), затем Windows, затем Linux.
- **Стек:** десктоп — Rust + Tauri; iPhone — Swift/SwiftUI/AVFoundation.

5. Любое новое архитектурное решение — фиксировать новым ADR в [12-decisions-log.md](12-decisions-log.md).

## Принципы документации

- **Без «TBD» в требованиях и дизайне.** Если что-то не решено — это явно помечено как «решение отложено
  до владельца» с дефолтом, который не блокирует работу.
- **Каждое решение — с обоснованием.** Чтобы не перепринимать.
- **Конкретика.** Форматы, порты, типы сообщений, имена файлов, библиотеки — явно.
- **Перекрёстные ссылки** между документами вместо дублирования.
