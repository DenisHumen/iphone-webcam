# 07 — UI/UX

Связано: [04-ios-app.md](04-ios-app.md), [05-desktop-app.md](05-desktop-app.md).
Это текстовая спецификация экранов и состояний. Высокоточные визуальные макеты можно собрать отдельно
(в т. ч. через визуальный компаньон брейнсторминга) на этапе реализации UI.

## 1. Язык дизайна

- **Минимализм и ясность.** Видео — главный объект; элементы управления не перетягивают внимание.
- **Тёмная тема по умолчанию** (видео лучше смотрится на тёмном), светлая — опционально.
- **Крупные понятные статусы.** Состояние канала/режима читается мгновенно.
- Сетка с воздухом, скруглённые карточки, мягкие тени, один акцентный цвет.
- **Семафор качества канала:** 🟢 хорошо (есть запас) · 🟡 впритык (адаптация активна) · 🔴 проблемы
  (идёт деградация/переподключение).
- Анимации — сдержанные, информативные (смена режима/камеры — лёгкий переход, не отвлекающий).

## 2. Десктоп — экраны и состояния

### 2.1. Состояния приложения

`Disconnected → Discovering/Pairing → Connecting → Handshaking → SpeedTest → Ready → Streaming →
(Reconnecting) → Error`. Каждое отражается в UI явно.

### 2.2. Экран подключения (Disconnected/Pairing)

Десктоп — сервер на Wi-Fi: он показывает QR-код, а **iPhone сканирует его и подключается сам**
(десктоп не «ищет» телефоны по Wi-Fi — он лишь анонсирует себя по mDNS, чтобы телефон нашёл его в
списке). По USB телефоны определяются автоматически через usbmuxd.

```
┌─────────────────────────────────────────────────────────┐
│  ClearCam — подключение                          ⚙  ─ □ ✕ │
├─────────────────────────────────────────────────────────┤
│                                                          │
│   Wi-Fi                          По USB-кабелю            │
│   ┌─────────────┐                (определяются авто):     │
│   │   [ QR ]    │                • iPhone Дениса          │
│   │             │                         [Подключить]    │
│   └─────────────┘                                         │
│   Откройте ClearCam на iPhone                             │
│   и отсканируйте QR-код.         Ручной ввод:             │
│   host 192.168.1.42 · порт 7000  host + токен ▾           │
│   токен действует 5 минут                                 │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 2.3. Главный экран (Streaming)

```
┌───────────────────────────────────────────────────────────────────┐
│ ClearCam   ● USB · 1080p60 · RAW            🔋 82%    ⚙  ─ □ ✕      │
├──────────────────────────────────────────┬────────────────────────┤
│                                          │  Камера                 │
│                                          │  [Фронт][Wide•][Ultra]  │
│                                          │  [Tele]                 │
│              ЖИВОЕ ПРЕВЬЮ                 │                         │
│            (принимаемый поток)            │  Режим                  │
│                                          │  ◉ Авто  ○ RAW  ○ Lossy │
│                                          │  Разрешение: 1080p ▾    │
│                                          │  FPS: 60 ▾              │
│                                          │                         │
│                                          │  Канал  🟢              │
│                                          │  Битрейт  1.49 Гбит/с   │
│                                          │  FPS  60 · Задержка 38мс│
│                                          │  Потери  0.0%           │
├──────────────────────────────────────────┤                         │
│ [⏺ Запись]   [Тест скорости]   [⏹ Стоп]  │  Виртуальная камера: ✓  │
└──────────────────────────────────────────┴────────────────────────┘
```

Элементы:

- **Шапка:** активный канал (USB/Wi-Fi), текущий режим (res/fps/RAW|Lossy), заряд телефона, настройки.
- **Превью:** живой принимаемый поток (downscaled, см. [05](05-desktop-app.md) §7).
- **Камера:** переключатель объективов (активный подсвечен), приходит из `CAMERA_LIST`.
- **Режим:** Авто (адаптивный движок) / принудительно RAW / принудительно Lossy; ручной выбор res/fps
  (в пределах caps); при ручном — предупреждение, если не влезает.
- **Метрики:** семафор канала, битрейт (мини-график), fps, задержка, потери — обновление ≥1 Гц.
- **Действия:** запись (опц.), повторный тест скорости, стоп.
- **Индикатор виртуальной камеры:** активна/нет (видна ли система-камера приложениям).

### 2.4. Оверлей теста скорости

Модальное окно с прогрессом ramp, измеренным goodput/RTT/джиттером и рекомендованным режимом + кнопки
«Применить рекомендованный» / «Выбрать вручную».

### 2.5. Состояния ошибок/переподключения

Ненавязчивый баннер: «Wi-Fi ослаб — режим снижен до 1080p Lossy» (🟡) или «Связь потеряна,
переподключаюсь…» (🔴) с индикатором. Виртуальная камера при разрыве отдаёт «заставку» (последний кадр
/ логотип «Нет сигнала»), не пропадает из системы.

## 3. iPhone — экраны

### 3.1. Connect (скан QR)

Полноэкранный видоискатель с рамкой для QR; подсказка «Наведите на QR-код на экране компьютера»;
кнопка «Ввести вручную»; статус подключения. Опционально — список найденных по mDNS компьютеров
(для удобства; токен всё равно берётся из QR).

### 3.2. Streaming

```
┌───────────────────────┐
│  ● Подключено · USB    │
│                       │
│     ВИДОИСКАТЕЛЬ       │
│   (что снимает камера) │
│                       │
│  RAW · 1080p60        │
│  🔋 82%  🌡 OK  ▲32Мб/с│
│                       │
│ [Фронт][Wide•][Ultra] │
│        [ ⏹ Стоп ]     │
└───────────────────────┘
```

- Видоискатель, активный объектив (можно менять и с телефона), режим, заряд, тепло, исходящий битрейт.
- Большая кнопка «Стоп». Экран не гаснет во время трансляции.

### 3.3. Settings

Камера по умолчанию, разрешение/fps по умолчанию, поведение экрана, доверенные компьютеры (USB
pairing), о приложении.

## 4. Ключевые UX-принципы

- **Подключение ≤ 3 действий:** открыть приложение на iPhone → сканировать QR → (авто тест скорости) →
  готово. USB — ещё проще (авто).
- **Честность вместо зависаний:** если режим невозможен — UI прямо это говорит и предлагает достижимый.
- **Без модальной перегрузки:** деградация/адаптация — баннеры, не блокирующие диалоги.
- **Симметрия управления:** объектив можно менять и с ПК, и с телефона; состояние синхронно.

## 5. Доступность

Контраст по WCAG AA, поддержка клавиатурной навигации в десктоп-UI, понятные подписи статусов (не
только цвет — иконка/текст), масштабируемый шрифт.
