# ClearCam

> Рабочее название (можно сменить). Репозиторий: `iphone_webcam`.

**ClearCam** превращает iPhone в высококачественную (вплоть до несжатой) веб-камеру для компьютера.
iPhone снимает видео и передаёт его на десктоп по Wi-Fi или USB; десктоп показывает живое
превью, даёт управление и публикует поток как **системную виртуальную камеру**, которую видят
Zoom, Google Meet, OBS, приложения записи и т. д.

Главная идея — **честное качество**: передавать истинно несжатое видео, когда канал это позволяет,
и автоматически переключаться на режим «визуально без потерь» (лёгкое сжатие, неотличимое глазом),
когда не позволяет. Что именно влезает в канал — решает встроенный **тест скорости**.

---

## Ключевые возможности

- 📷 Переключение камер (объективов) iPhone прямо с десктопа: фронтальная, основная, ультраширик, телевик.
- 🎚 Гибридное качество: истинный **raw (YUV 4:2:0)** ↔ **визуально без потерь (VideoToolbox)**, выбор автоматический.
- 🔋 Индикатор заряда телефона на десктопе.
- 📊 Реальный битрейт, fps, задержка, потери — в реальном времени.
- 🧪 Тест скорости перед стартом: проверяет, какой режим стабильно потянет сеть.
- 🔌 Два транспорта под одним протоколом: **Wi-Fi** (TCP, автопоиск mDNS, привязка по QR) и **USB** (usbmuxd).
- 🖥 Кросс-платформенный десктоп: **macOS → Windows → Linux**.

## Стек (кратко)

| Часть | Технологии |
|---|---|
| iPhone-клиент | Swift, SwiftUI, AVFoundation, VideoToolbox, Network.framework |
| Десктоп-ядро | Rust |
| Десктоп-UI | Tauri (Rust backend + веб-фронтенд) |
| Виртуальная камера | CMIO Camera Extension (macOS) · Media Foundation (Windows) · v4l2loopback (Linux) |
| Транспорт | TCP поверх Wi-Fi и поверх USB (usbmuxd / libimobiledevice) |

Подробности и обоснование — в [docs/09-tech-stack.md](docs/09-tech-stack.md) и [docs/12-decisions-log.md](docs/12-decisions-log.md).
